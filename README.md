# 보안 기초 학습 퀴즈

## 1. 서비스 소개
정보보안을 처음 배우는 대학생이 기초 개념을 간단한 문제로 복습할 수 있는 웹페이지입니다. 주요 행동은 문제 읽기 → 답 선택 → 정답 및 해설 확인입니다.

## 2. 중간고사 추가 기능
기존 퀴즈 흐름의 정답 확인 단계 뒤에 **오답 노트** 기능을 추가한 예시입니다. 틀린 문제를 자동으로 저장하고 분야별로 필터링하거나 복습 완료 처리할 수 있습니다. 브라우저 로컬 저장소를 사용하므로 새로고침해도 목록이 남습니다.


## 3. 사용자 행동과 조건 및 화면 반응
| 행동 | 확인 조건 | 화면 반응 | 다음 행동 |
|---|---|---|---|
| 정답 확인 | 답 선택 여부 | 미선택 시 선택 안내 | 답 선택 후 재확인 |
| 오답 선택 | 정답과 일치하지 않음 | 해설 표시, 오답 노트 자동 추가 | 다음 문제 또는 오답 확인 |
| 분야 선택 | 해당 분야에 저장된 문제 존재 여부 | 해당 목록 또는 결과 없음 안내 | 다른 분야 선택 |
| 복습 완료 | 저장된 문제 선택 | 목록에서 해당 문제 제거 | 다른 문제 복습 |
| 전체 삭제 | 오답이 하나 이상 존재 | 목록 삭제, 취소 버튼 표시 | 삭제 취소 또는 퀴즈 풀기 |
| 삭제 취소 | 이전 삭제 기록 존재 | 삭제 전 목록 복원 | 계속 복습 |
| 퀴즈 재시작 | 별도 조건 없음 | 퀴즈 문제/점수 초기화, 오답 노트는 유지 | 첫 문제부터 풀기 |

## 4. 테스트 기록

| 테스트 | 방법 | 예상 결과 | 실제 결과 |
|---|---|---|---|
| 정상 경로 | 오답 선택 → 정답 확인 | 오답 노트에 문제 추가 | 미실시 |
| 오류 경로 | 답 선택 없이 정답 확인 | 선택 안내 문구 출력 | 미실시 |
| 결과 없음 | 오답 없는 분야 선택 | 해당 분야 오답 없음 안내 | 미실시 |
| 삭제/취소 | 오답 전체 삭제 → 삭제 취소 | 목록이 복구됨 | 미실시 |
| 완료 처리 | 오답의 복습 완료 클릭 | 해당 문제 목록에서 제거 | 미실시 |
| 저장 확인 | 오답 저장 후 새로고침 | 오답 유지 | 미실시 |
| 모바일 확인 | 브라우저 폭을 좁혀서 조작 | 버튼 겹침 없이 조작 | 미실시 |


## 5. 제출 주소
- GitHub 저장소: 아직 입력하지 않음
- 배포된 웹페이지: 아직 입력하지 않음

GitHub 저장소의 Settings → Pages에서 `Deploy from a branch`, `main`, `/(root)`를 선택해 배포할 수 있습니다.
